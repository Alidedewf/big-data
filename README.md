# Big-Data

Практические работы по дисциплине **«Методы анализа и обработки больших данных»**.

Цель — освоить загрузку, очистку, анализ и визуализацию данных с помощью Python.

## Инструменты

- Python 3
- pandas — загрузка и обработка таблиц
- NumPy — числовые вычисления
- Matplotlib — построение графиков
- VS Code — редактор кода
- Git — история изменений и работа с ветками

## Организация работ

Для каждой практической работы создаётся отдельная ветка:

- `main` — завершённые практические работы;
- `practice-01` — практическая работа №1;
- `practice-02` — практическая работа №2;
- далее — по тому же принципу.

Каждая работа также хранится в своей папке. После завершения ветка объединяется с `main`, поэтому все готовые работы доступны вместе и не перезаписывают друг друга.

Планируемая структура репозитория:

```text
Big-Data/
├── README.md
├── .gitignore
├── requirements.txt
└── practice-01/
    ├── README.md            # Задание, порядок запуска и выводы
    ├── main.py              # Код практической работы
    ├── data/
    │   └── iris.csv         # Исходный набор данных
    └── report/
        ├── screenshots/    # Скриншоты выполнения
        └── histogram.png   # График распределения признака
```

Это план структуры: файлы и папки добавляются по мере выполнения заданий. Для следующих работ создаются папки `practice-02`, `practice-03` и т. д.

## Настройка окружения

Команды выполняются в терминале из корня репозитория.

Создание виртуального окружения:

```bash
python3 -m venv .venv
```

Активация на macOS / Linux:

```bash
source .venv/bin/activate
```

Активация в Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

В Windows для создания окружения может потребоваться команда `py -m venv .venv`.

Создать в корне файл `requirements.txt`:

```text
pandas
numpy
matplotlib
```

Установить библиотеки в активированное окружение:

```bash
python -m pip install -r requirements.txt
```

В VS Code выбрать интерпретатор из `.venv` через команду **Python: Select Interpreter**.

## Работа с Git

### Первоначальная настройка

Если папка ещё не является Git-репозиторием:

```bash
git init -b main
```

До добавления файлов создать `.gitignore` в корне:

```gitignore
.venv/
__pycache__/
*.pyc
.DS_Store
```

Сохранить начальное состояние:

```bash
git add README.md .gitignore
git commit -m "Добавить описание репозитория"
```

### Начало практической работы

Создавать новую ветку из `main`, предварительно сохранив текущие изменения:

```bash
git switch main
git switch -c practice-01
```

Работать в папке `practice-01/`. После выполнения очередного этапа проверить изменения и сохранить их:

```bash
git status
git add practice-01/
git commit -m "Практическая 1: добавить загрузку данных"
```

Общие файлы, например `requirements.txt`, добавляются в коммит отдельно, если они изменены.

### Завершение практической работы

Когда код проверен и отчёт готов, сохранить все относящиеся к работе изменения в коммитах и объединить ветку с `main`:

```bash
git switch main
git merge practice-01
```

Следующую работу начинать из обновлённой `main` в новой ветке `practice-02` и папке `practice-02/`.

Git хранит историю локально. Для публикации на GitHub потребуется отдельно создать удалённый репозиторий и подключить его. Небольшие открытые учебные датасеты можно хранить вместе с кодом, указав источник; виртуальное окружение в репозиторий не добавляется.

## Практическая работа №1

**Тема:** Введение в методы анализа и обработки больших данных. Работа с данными в Python (pandas).

**Планируемый датасет:** Iris.

План выполнения:

- [ ] Подготовить окружение и установить библиотеки.
- [ ] Скачать датасет и указать его источник.
- [ ] Загрузить CSV с помощью `pd.read_csv()`.
- [ ] Вывести первые пять строк через `df.head()`.
- [ ] Изучить структуру и статистику: `df.info()`, `df.describe()`.
- [ ] Проверить количество пропусков и дубликатов.
- [ ] Обработать пропуски при наличии и удалить дубликаты строк.
- [ ] Сравнить состояние данных до и после очистки.
- [ ] Найти среднее, минимум и максимум числовых признаков.
- [ ] Построить и сохранить гистограмму одного признака.
- [ ] Подготовить отчёт и ответить на контрольные вопросы.

Если пропусков или дубликатов нет, это фиксируется в отчёте: искусственно добавлять их для выполнения задания не требуется.

### Содержание отчёта

1. Краткое определение больших данных и их характеристик.
2. Источник и описание выбранного датасета.
3. Скриншот первых пяти строк.
4. Результаты проверки и очистки данных: пропуски, дубликаты, число строк до и после.
5. Среднее, минимальное и максимальное значения одного признака.
6. График распределения признака и краткое пояснение.
7. Ответы на контрольные вопросы и вывод по работе.
