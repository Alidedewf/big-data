# Big-Data

Практические работы по дисциплине **«Методы анализа и обработки больших данных»**.

Цель — освоить загрузку, очистку, анализ и визуализацию данных с помощью Python.

## Инструменты

- Python 3
- pandas — загрузка и обработка таблиц
- NumPy — числовые вычисления
- Matplotlib — построение графиков
- VS Code — редактор кода
- Git — история изменений и работа с ветками

## Организация работ

Для каждой практической работы создаётся отдельная ветка:

- `main` — завершённые практические работы;
- `practice-01` — практическая работа №1;
- `practice-02` — практическая работа №2;
- далее — по тому же принципу.

Каждая работа также хранится в своей папке. После завершения ветка объединяется с `main`, поэтому все готовые работы доступны вместе и не перезаписывают друг друга.

Планируемая структура репозитория:

```text
Big-Data/
├── README.md
├── .gitignore
├── requirements.txt
└── practice-01/
    ├── README.md            # Задание, порядок запуска и выводы
    ├── main.py              # Код практической работы
    ├── data/
    │   └── iris.csv         # Исходный набор данных
    └── report/
        ├── screenshots/    # Скриншоты выполнения
        └── histogram.png   # График распределения признака
```

Это план структуры: файлы и папки добавляются по мере выполнения заданий. Для следующих работ создаются папки `practice-02`, `practice-03` и т. д.

## Настройка окружения

Команды выполняются в терминале из корня репозитория.

Создание виртуального окружения:

```bash
python3 -m venv .venv
```

Активация на macOS / Linux:

```bash
source .venv/bin/activate
```

Активация в Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

В Windows для создания окружения может потребоваться команда `py -m venv .venv`.

Создать в корне файл `requirements.txt`:

```text
pandas
numpy
matplotlib
```

Установить библиотеки в активированное окружение:

```bash
python -m pip install -r requirements.txt
```

В VS Code выбрать интерпретатор из `.venv` через команду **Python: Select Interpreter**.
