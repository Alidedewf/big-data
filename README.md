## 3. Кодирование категориальных признаков

Определены категориальные признаки `sex`, `embarked` и `class`. По условию задания One-Hot Encoding применён к `sex` и `embarked`:

```python
df_encoded = pd.get_dummies(
    df_clean,
    columns=["sex", "embarked"],
    drop_first=True,
    dtype=int
)
```

Каждый новый столбец содержит индикатор категории: 1 — принадлежит, 0 — не принадлежит. Параметр `drop_first=True` исключает по одной базовой категории. Базовые категории здесь — `female` и порт `C`.

## 4. Стандартизация числовых признаков

Возраст и стоимость билета имеют разные единицы и масштабы. Для их преобразования использован `StandardScaler`:

```python
df_scaled = df_encoded.copy()
scaler = StandardScaler()
df_scaled[["age", "fare"]] = scaler.fit_transform(
    df_encoded[["age", "fare"]]
)
```

Формула: **z = (x − μ) / σ**, где μ — среднее столбца, σ — его стандартное отклонение с делителем N. `fit` вычисляет параметры, `transform` применяет преобразование.

## 6. Ответы на контрольные вопросы

### 1. Какие существуют способы обработки пропусков?

Удаление строк или столбцов; замена средним, медианой или модой; выделение категории «неизвестно»; заполнение по группам; интерполяция для подходящих упорядоченных данных; прогнозирование пропущенных значений моделью. Метод выбирают с учётом смысла признака, количества и причин пропусков. Иногда добавляют отдельный индикатор отсутствия значения.

### 2. В чём разница между Label Encoding и One-Hot Encoding?

Label Encoding сопоставляет каждой категории целочисленную метку. Если такие числа подать модели как обычный числовой признак, она может воспринять искусственный порядок. One-Hot Encoding создаёт отдельные индикаторы категорий и не задаёт между ними числового расстояния. При большом числе категорий он значительно увеличивает число столбцов. В scikit-learn `LabelEncoder` предназначен прежде всего для целевой переменной; для входных категориальных признаков существуют `OrdinalEncoder` и `OneHotEncoder`.

### 3. Что дают нормализация и стандартизация данных?

Они приводят признаки к согласованным масштабам, что важно для алгоритмов, чувствительных к расстояниям и величине признаков. В контексте задания под нормализацией часто понимают Min-Max-преобразование в диапазон [0, 1] по обучающим минимуму и максимуму. Стандартизация вычитает среднее и делит на стандартное отклонение. Термин «нормализация» также используется для приведения векторов к единичной норме. В работе применена именно стандартизация.

### 4. Для чего используется тепловая карта корреляции?

Она показывает направление и силу попарных связей между числовыми признаками. Для корреляции Пирсона значения близко к +1 означают сильную положительную линейную связь, к −1 — отрицательную, около 0 — слабую линейную связь. Нулевая корреляция не исключает нелинейную зависимость. Карта помогает замечать связанные и дублирующие признаки, но корреляция не доказывает причинность.
