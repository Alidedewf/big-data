## 1. Теоретические сведения

Большие данные — наборы данных, объём, скорость поступления или разнообразие которых требуют специальных подходов к хранению и обработке. Их основные характеристики обозначают как 3V:

- **Volume (объём)** — большое количество данных.
- **Velocity (скорость)** — быстрое поступление и обновление данных, необходимость своевременной обработки.
- **Variety (разнообразие)** — различные форматы: таблицы, тексты, изображения, аудио и другие.

Основные этапы работы с данными: сбор, хранение, очистка, анализ и визуализация. В данной работе используется небольшой учебный датасет Iris. Он не относится к большим данным, но позволяет освоить базовые операции обработки.

## 4. Первичный анализ и очистка

Метод `df.info()` показал, что таблица содержит четыре числовых столбца и один строковый. Во всех столбцах заполнены 150 значений. Метод `df.describe()` использован для получения описательной статистики числовых признаков.

Проверка пропусков и повторных строк:

```python
print(df.isna().sum())
print(df.duplicated().sum())
```

Пропусков не обнаружено, поэтому заполнение средними значениями или удаление строк с пропусками не потребовалось. Найдена **одна повторная строка**, совпадающая с другой строкой по всем пяти столбцам.

В соответствии с заданием повтор удалён:

```python
rows_before = len(df)
df = df.drop_duplicates().reset_index(drop=True)
```

`drop_duplicates()` сохраняет первое вхождение строки и удаляет последующие совпадения. `reset_index(drop=True)` заново нумерует строки, не добавляя старый индекс в отдельный столбец. Исходный CSV при этом не изменяется: очистка выполняется в памяти.

| Показатель | До очистки | После очистки |
| --- | ---: | ---: |
| Количество строк | 150 | 149 |
| Количество столбцов | 5 | 5 |
| Количество пропущенных значений | 0 | 0 |
| Количество повторных строк | 1 | 0 |

Вывод программы:

```text
Строк до очистки: 150
Строк после очистки: 149
Пропусков после очистки: 0
Дубликатов после очистки: 0
```

Совпадение измерений само по себе не доказывает ошибку данных: у разных цветков могут быть одинаковые значения. В этой учебной работе удаление выполнено по условию задания.

## 6. Визуализация распределения

Построена гистограмма длины чашелистика с помощью Matplotlib:

```python
plt.hist(df["sepal_length"], bins=10, edgecolor="black")
plt.title("Распределение длины чашелистика")
plt.xlabel("Длина чашелистика, см")
plt.ylabel("Количество цветков")
plt.tight_layout()
```

Значения разделены на 10 интервалов. Горизонтальная ось показывает длину чашелистика, вертикальная — количество цветков в соответствующем интервале. График сохранён в `report/histogram.png`.

![Распределение длины чашелистика после очистки](report/histogram.png)

Длина чашелистика изменяется от 4.3 до 7.9 см. Большинство наблюдений сосредоточено примерно между 4.7 и 6.8 см; значения выше 7 см встречаются реже. Гистограмма построена по всем видам ирисов вместе и показывает общее распределение признака.

## 7. Ответы на контрольные вопросы

### 1. Какие характеристики определяют большие данные?

Основные характеристики — объём, скорость поступления и разнообразие форматов (3V). Дополнительно часто рассматривают достоверность данных (Veracity) и ценность получаемой информации (Value).

### 2. В чём отличие структурированных и неструктурированных данных?

Структурированные данные организованы по определённой схеме, например в таблице со столбцами и заданными типами значений. Пример — используемый датасет Iris. Неструктурированные данные не представлены в виде такой фиксированной табличной схемы: это, например, свободный текст, фотографии, аудио и видео. Для их анализа обычно требуется предварительное извлечение признаков.

### 3. Какие библиотеки Python используются для анализа данных?

pandas используется для работы с таблицами, загрузки, очистки и группировки данных. NumPy предоставляет массивы и числовые операции. Matplotlib применяется для построения графиков. Также используются Seaborn для статистической визуализации и scikit-learn для машинного обучения.

### 4. Зачем нужна предобработка данных перед анализом?

Предобработка помогает обнаружить и обработать пропуски, ошибочные значения, несогласованные типы и нежелательные повторы. Это повышает качество данных и снижает риск искажённых выводов. Способ обработки выбирается с учётом смысла данных и цели анализа.
